# AI Code Challenge — Student App

Стартовий вебпроєкт для учнів 11 класу.

## Початок роботи

1. Завантажте проєкт через **Code → Download ZIP**.
2. Розпакуйте архів.
3. Перейменуйте розпаковану папку на `student-app`.
4. Відкрийте VS Code.
5. Виберіть **File → Open Folder** і відкрийте `student-app`.

## Запуск сайту

Відкрийте термінал VS Code через **Terminal → New Terminal**.

**Mac:**
```bash
python3 -m http.server 8001 --bind 127.0.0.1
```

**Windows:**
```powershell
py -m http.server 8001 --bind 127.0.0.1
```

Відкрийте браузер і перейдіть за адресою:

http://127.0.0.1:8001/

Для зупинки сервера натисніть `Ctrl + C` у терміналі.

## Робота з GitHub Copilot

У Місії 01 використовуйте два режими:

- **Plan** — аналіз і планування без змін файлів.
- **Agent** — реалізація погодженого плану.

У Місії 01 Copilot Agent дозволено змінювати лише:

- `index.html`
- `css/style.css`

Не дозволяйте Copilot видаляти або змінювати інші файли.

## Результати роботи

Після виконання Місії 01 збережіть:

- HTML/CSS-фрагмент власного проєкту;
- Product Brief;
- журнал рішень;
- JSON-експорт NextLab.

Не видаляйте папку `student-app` після завершення місії. Вона знадобиться для наступних занять.
